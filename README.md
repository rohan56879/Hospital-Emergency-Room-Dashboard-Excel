# Hospital-Emergency-Room-Dashboard-Excel
An interactive Hospital Emergency Room Dashboard developed using Microsoft Excel to analyze and visualize patient and emergency-room data.
📊 Dashboard Features
Total Patient Count
Average Waiting Time
Patient Satisfaction Score
Admission Status
Patient Attendance Status
Gender-wise Analysis
Age-group Analysis
Department-wise Patient Referrals
Monthly and Yearly Analysis using filters
🛠️ Tools & Techniques
Microsoft Excel
Pivot Tables
Pivot Charts
Slicers
Data Cleaning
Data Analysis
Data Visualization
Dashboard Design
🎯 Objective

The objective of this project is to transform hospital emergency-room data into an interactive dashboard that makes it easier to monitor patient statistics and identify useful patterns.
Through this project, I strengthened my skills in Excel, data visualization, dashboard creation, and presenting data-driven insights.
